# Q2 · Real sites and the frequency decision (weeks 11–20)

**Question:** Which frequency, at which site, with which orbit?

**Goal:** Apply the first-order model to real candidate sites using their own surface and dielectric data, add a first-order signal-to-clutter ratio (SCR), and work out what orbit our processing needs.

**Exit criterion:** The week-20 decision review picks the frequency, bandwidth, target site and observation strategy. Consider inviting Adrian.
