# Q3 · Second-order modeling and hardware (weeks 21–30)

**Question:** Can we see the tube through the clutter, and what exactly do we build?

**Goal:** Model clutter at the chosen site with second-order methods (Gaussian roughness statistics, DEM-based clutter), show what processing recovers, and start benchtop hardware.

**Exit criterion:** Hardware requirements frozen, with the detectability result as the evidence behind them.
